# mini_rpg

Текстовая мини-RPG на Nim. Один вечер, один герой, одна палка и один барон,
которого неплохо бы убить.

## Сюжет

Герой приходит в себя в холодной пещере и не помнит, как там оказался.
На полу валяется кривая палка — единственное оружие. Снаружи дорога ведёт
в город Эльдхейм: по пути придётся разобраться с гоблином и дорожным
разбойником.

В городе есть кузнец, алхимик, трактир с крысиным подвалом и доска
объявлений. Два квеста — «Крысы в подвале» и «Гоблинская сталь» — дают опыт,
золото и повод заглянуть в лес. На вырученное золото покупается оружие и
зелья.

За городом стоит замок барона Кровавого Клыка. На входе скелет-стражник,
в тронном зале — сам барон. Победа над ним завершает игру.

## Как запустить

Нужен Nim 1.6.6 или новее.

```bash
nimble build
./mini_rpg
```

Или без nimble:

```bash
nim c -r src/mini_rpg.nim
```

## Управление

Всё меню — цифры и Enter. В бою доступны три действия:

- атаковать;
- выпить зелье (если есть в сумке);
- бежать (кроме боя с боссом).

В городе пункт «Открыть сумку» позволяет взять купленное оружие в руки
и выпить зелье вне боя. Без этого меч останется лежать в сумке.

## Механика

- **Урон**: сила героя плюс бонус оружия минус защита врага, минимум 1.
- **Уровни**: опыт накапливается, порог растёт на 10 за уровень. За уровень
  герой получает 8 максимума HP и 1 силы.
- **Инвентарь**: 12 слотов. Трофеи для квестов не продаются.
- **Квесты**: цель «убить N врагов» считается по счётчику убийств, цель
  «принести предмет» забирает трофеи при сдаче.
- **Трактир**: 10 золота за полное восстановление здоровья.

Для победы над бароном нужно подготовиться: пройти оба квеста, купить меч
и взять пару зелий. С одной палкой в замок лучше не ходить.

## Тесты

```bash
nimble test
```

Проверяются расчёт урона, повышение уровня, экипировка, покупки, прогресс
и сдача квестов, а также два сценария баланса: подготовленный герой
побеждает босса, неподготовленный — погибает.

Баланс целиком проверяется отдельным скриптом:

```bash
nim c -r --path:src tools/balance_check.nim
```

Он проходит путь «пещера → дорога → два квеста → снаряжение → замок» без
участия игрока и печатает характеристики героя на каждом этапе.

## Структура

```
src/mini_rpg.nim        точка входа и порядок сцен
src/mini_rpg/types.nim  типы и константы баланса
src/mini_rpg/items.nim  предметы, инвентарь, экипировка
src/mini_rpg/enemies.nim враги и расчёт урона
src/mini_rpg/quests.nim квесты и их прогресс
src/mini_rpg/battle.nim бой: интерактивный и автоматический
src/mini_rpg/shops.nim  магазины, трактир, доска объявлений
src/mini_rpg/scenes.nim сцены и переходы между локациями
src/mini_rpg/render.nim вывод состояния, инвентаря и журнала
src/mini_rpg/ui.nim     ввод, меню, паузы
tests/test_game.nim     тесты на unittest
tools/balance_check.nim проверка прогрессии
```

Все числа баланса — стартовые характеристики, цены, награды, сила врагов —
собраны в `types.nim`, `items.nim`, `enemies.nim` и `quests.nim`, чтобы
правки не расползались по сценам.
